## 首页、按键和声音的去向

按 **Ctrl+Tab** 返回模块首页，用上下选择，Enter进入。返回首页后保留当前选择，不会自动跳到另一个模块。

| 模块 | 用途 | SD卡 |
|---|---|---|
| STUDIO | 多轨演奏、循环编曲、鼓机、和弦和琶音 | 基础波形与LOCAL项目可不插卡；SMP音色与SD项目需要卡 |
| SOUND LAB | 录音、裁剪、处理采样、基础波形合成、制作音色 | 必须插卡 |
| PLAYER | 浏览SD目录，播放WAV／MP3 | 必须插卡 |

SOUND LAB制作的音色保存到SLOT 1～4后，STUDIO通过SMP1～SMP4使用。PLAYER播放的是音频文件本身，不会应用音色槽中的滤波、包络和LFO。

### 方向键和琴键

下文的上／下／左／右，对应键帽方向符号：**; / . / , / /**。手册中写“左右”时，指逗号键和斜杠键。

旋律键盘为两排半音排列，上排低八度、下排高八度。以下以C调为例：

| 音 | C | C♯ | D | D♯ | E | F | F♯ | G | G♯ | A | A♯ | B |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 上排：低八度 | E | 4 | R | 5 | T | Y | 7 | U | 8 | I | 9 | O |
| 下排：高八度 | Z | D | X | F | C | V | G | B | H | N | J | M |

E～O这一排是12个半音，Z～M是高八度的12个半音。D键是高八度的升do。改项目主音后，键位整体移调。

音名后的数字表示八度编号，例如C4为中央C；C2–B3表示当前键盘从C2覆盖到B3，不是两个轨道。

每条旋律轨最多**4复音**，可以手动弹完整七和弦；三条旋律轨合计最多12个旋律音。SOUND LAB单独试听也是4复音。超过上限会替换较旧声部。

## STUDIO：多轨编曲

### 四轨总览

S1、S2、S3是旋律轨，S4是鼓组。每条彩色循环条显示各步的内容，播放时显示当前位置。

| 操作 | 按键 |
|---|---|
| 选择音轨 | 上／下 |
| 进入选中的音轨 | Enter；Tab也可切换总览／详情 |
| 详情返回总览 | Tab |
| 查看前／后小节 | 总览中左／右 |
| 开始／停止循环 | Space |
| 全部声音停止、释放HOLD | Backspace |
| 选中音轨静音／恢复 | 总览中M |
| 项目总音量 MASTER | - 降低，= 提高；屏幕显示0～100%，每次5个百分点 |
| 项目速度 BPM | [ 降低，] 提高；40～240，每次5 BPM |
| 项目主音／音阶 | Ctrl+K |
| 项目文件界面 | P；或Ctrl+S保存、Ctrl+L读取 |
| 整轨清空 | Fn+Ctrl+D → Enter确认；Tab取消 |
| 撤销最近一次项目编辑 | Ctrl+Z |

**BPM和MASTER属于整个项目**。每条轨道还有自己的音量。静音不删除音符，循环时钟仍继续。

当前循环长度可设1／2／4小节；每小节16格，每格为一个十六分音符。进入音轨详情后用 **Fn+J** 切换长度。缩短长度会处理超出新范围的内容，修改前建议先保存。

### S1～S3：实时演奏 LIVE

进入旋律轨后直接按琴键演奏。

| 操作 | 按键 |
|---|---|
| LIVE／STEP切换 | Ctrl+E；K不是切换键 |
| 降／升一个八度 | Fn+左／右 |
| 切换音色 | A，循环基础波形和SMP1～SMP4 |
| LIVE详情页切换 | Enter：PLAY／NOTES／SOUND |
| 当前音轨音量 | Fn+G降低，Fn+H提高 |
| 当前音轨静音 | Fn+M |
| 实时循环录音开／关 | Ctrl+R |
| 播放／停止已有循环 | Space |

实时录音：停止状态按Ctrl+R会先做四拍预备；已经播放时，等下一小节开始录入。录入的是当前音轨，循环中可以叠加音符，再按Ctrl+R结束。用Space回放检查，再保存项目。

### STEP：逐步填写旋律

1. 进入S1～S3，按Ctrl+E切到STEP。
2. 左右移动黄色编辑游标，上下选择音符时值。
3. 按一个琴键或同时按几个键，**全部松开后提交一次**。
4. 用Space试听循环。

| 时值 | 占用格数 |
|---|---|
| 1/1 全音符 | 16 |
| 1/2 二分音符 | 8 |
| 1/4 四分音符 | 4 |
| 1/8 八分音符 | 2 |
| 1/16 十六分音符 | 1 |

| 操作 | 按键 |
|---|---|
| 移动一格 | 左／右，长按连续移动 |
| 选择时值 | 上／下 |
| 跳过当前时值，保留已有音符 | Enter |
| 写入休止：清空当前时值范围 | Fn+Enter |
| 删除当前格起点的音符／和弦 | Fn+D |
| 整轨清空并确认 | Fn+Ctrl+D |
| 复制／粘贴当前格起点的音符或和弦 | Ctrl+C／Ctrl+V |
| 输入后自动前进开／关 | Ctrl+G |
| 撤销最近一次编辑 | Ctrl+Z |
| 换八度 | Fn+左／右 |

Fn+Enter会裁掉穿过选中范围的长音，保留范围外内容；普通Enter只是移动位置。黄色框是编辑位置，白色框是播放位置，两者可以不同。

### 调内和弦、手动七和弦与琶音

- **S**：开／关自动调内三和弦。
- **L**：循环ARP OFF／UP／DOWN／UP-DOWN。
- **Ctrl+A**：打开CHORD／ARP设置，上下选项、左右改值、Enter应用、Tab取消。

| 设置 | 含义 |
|---|---|
| CHORD | OFF或调内三和弦 |
| ARP | 关闭、上行、下行、往返 |
| RATE | 1/4、1/8、1/16，跟随项目BPM |
| GATE | 每个琶音的发声比例，10～100% |
| OCT RANGE | 1或2个八度 |
| HOLD | 松开琴键后继续琶音 |

C大调中，按do自动生成C–E–G，按la生成A–C–E。当前自动和弦仍是**三和弦**，没有自动七和弦选项；要手动弹七和弦，请关掉CHORD，再同时按四个琴键。例如C大调低八度 **E+T+U+O** 为C–E–G–B，即Cmaj7。

Ctrl+K选择项目主音和MAJOR／MINOR，Enter应用。改调会同时移调三条旋律轨，鼓组不移调。调内和弦按当前大小调生成；不在音阶内的半音键保持单音并提示OUT OF SCALE。

CHORD与ARP可以叠加。HOLD时换根音会替换旧内容；Backspace、切轨或离开相关页面会释放保持音。实时录音记录实际发出的和弦／琶音；STEP开启ARP时，会把所选时值内的琶音写成音符。

## S4：鼓组与鼓点编辑

进入S4默认是GRID，每行一种鼓声，每小节16格，上下滚动查看其他鼓声。

| 鼓声 | 中文 | 实时鼓垫键 |
|---|---|---|
| KICK | 底鼓 | Q |
| SNARE | 军鼓 | W |
| CLAP | 拍手 | E |
| C HAT | 闭镲 | R |
| O HAT | 开镲 | T |
| L TOM | 低音通鼓 | Y |
| H TOM | 高音通鼓 | U |
| PERC | 打击音 | I |

GRID行顺序为KICK、SNARE、C HAT、O HAT、CLAP、L TOM、H TOM、PERC；与鼓垫字母顺序略有区别。

| 操作 | 按键 |
|---|---|
| 选择鼓声行 | 上／下 |
| 移动步进位置 | 左／右 |
| 前／后一个小节 | Fn+左／右 |
| 填入／删除当前格鼓点 | Enter |
| 删除当前格 | Fn+D |
| 静音当前鼓声 | M |
| 静音整个S4 | Fn+M |
| GRID／PAD切换 | Ctrl+E |
| 进入／退出MIX | Fn+Enter |
| 播放／停止 | Space |
| 实时鼓点录音 | Ctrl+R |
| Swing减／加 | GRID或PAD中G／H |
| 切换鼓点预设 | S，会改变鼓点；可Ctrl+Z撤销 |
| 循环1／2／4小节 | Fn+J |
| 整个S4音量减／加 | Fn+G／H |

Q～I在GRID也能打鼓；直接填格不需要开启REC。推荐先在第1、5、9、13格填闭镲，再加底鼓和军鼓，按Space回放。

MIX中：上下换鼓声，G／H改该鼓音量，Z／X改音高，J或M静音，K独奏，Enter返回GRID。注意MIX的G／H调单鼓音量，GRID／PAD的G／H调Swing。

## 项目保存和读取

这是**STUDIO多轨项目**存档，与SOUND LAB音色槽是两套东西。

1. 在STUDIO按Ctrl+S或Ctrl+L打开文件界面。
2. 上下选SLOT 1～4。
3. 左右选择SAVE／LOAD／RENAME／SOURCE。
4. SOURCE项按Enter切LOCAL内部Flash或SD。
5. RENAME项按Enter输入名称，Enter确认。
6. SAVE／LOAD按Enter执行；覆盖或替换有改动的项目时，再按Enter确认。
7. Tab逐层取消／返回；看到成功结果再离开。

LOCAL和SD各有自己的四个项目槽，切换来源后看到EMPTY，不代表另一个来源的项目消失。改空槽名称只准备名字，仍需执行SAVE。

项目保存音符、鼓点、速度、调性、轨道音色编号、和弦／ARP设置、静音及音量等。选择SMP1～4保存的是音色槽引用，**不会把SD上的WAV和音色设置复制进LOCAL项目**。移动到另一张卡时要一起带上对应素材和音色槽。

## SOUND LAB：开始一个音色

从首页进入SOUND LAB后先选择工作方式：

| 选项 | 用途 |
|---|---|
| OPEN SESSION | 打开LAST工作状态或SLOT 1～4音色 |
| NEW SESSION | 新建空白，去FILES录音或导入WAV |
| BASIC SOURCES | 从SINE／TRIANGLE／SQUARE／SAW／WHITE NOISE开始 |

上下选、Enter进入。基础周期波以C4为根音，默认按住循环、松键释放；噪声没有稳定音高。基础音源也需要SD，会生成独立素材文件。

LAST是上次离开音色工坊时保存的工作状态，SLOT是供长期保存和STUDIO使用的音色库。新建空白不会删除已有音色槽。

### 分页导航

| 页面 | 用途 | 怎样操作 |
|---|---|---|
| PLAY | 琴键试听 | 选到即可使用，无需Enter |
| TRIM | 调整裁剪范围、SAVE TRIM | Enter进入编辑 |
| TONE | 包络、滤波、音高、OSC、LFO | Enter进入分组栏 |
| FILES | 保存、读取、录音、导入等 | 选到后上下选操作，Enter执行 |

外层**左右选页**。编辑TRIM／TONE时，Tab退出编辑；Backspace逐层返回。基础音源隐藏TRIM和采样LOOP等入口，只显示PLAY／TONE／FILES；录音和普通采样保留完整页面。

常用快捷键：Ctrl+S保存音色，Ctrl+L载入，Ctrl+M录音，Ctrl+O打开WAV，Ctrl+Tab回首页。PLAY中Fn+左右换试听八度。-／=调整试听所用总音量。

### 导入WAV

把要作为音色的WAV放到 **/PocketSynth/Samples/**，用FILES → OPEN WAV或Ctrl+O选择。这个音色导入列表与PLAYER的全卡目录浏览不同；当前只从此素材文件夹列出WAV。

音色载入长度为32～32768帧。24kHz时最长约1.37秒；录音可以远长于这个长度，再选择短片段作为音色。不能把MP3直接载入成SMP音色；MP3由PLAYER播放。

## 录音、选区试听和裁剪

### 录音和倒计时

1. FILES → RECORD MIC，或Ctrl+M。
2. 左右设置DELAY，0～60秒；Shift+左右每次5秒。
3. Enter开始。DELAY为0立即录音，否则倒计时结束后显示RECORDING。
4. 发声，电平条显示麦克风输入；**Enter停止并保留**。
5. 录音中Tab／Backspace取消。倒计时中Enter也可以取消。

录音直接写SD，格式24kHz、单声道、PCM16；不再等待声音阈值自动触发。需要采敲击声时，可设3秒倒计时，等RECORDING后再敲。没有实时监听，建议尾音结束后稍等再停止。

### TAKE / SELECT CLIP：先选要载入的片段

录完显示整段波形，绿色START、黄色END。波形从SD扫描，右上进度没完成时可以稍等。

| 操作 | 按键 |
|---|---|
| 选择START／END／MOVE | 上／下 |
| 调整范围 | 左／右 |
| 试听选区／停止 | Space；或按住E试听、松开停止 |
| 确认并载入选区 | Enter |
| 取消范围、回FILES | Tab／Backspace，原始录音仍在SD |

START只改开头，END只改结尾，MOVE整体移动选区。试听中改范围会先停止，调整停下约160ms后从新起点重播。

移动速度：普通左右至少约10ms并随整段长度适配；长按约0.65秒变5倍、1.6秒变20倍。Shift+左右为10倍步长，Ctrl+左右每次1秒，Fn+左右精调1个源采样点。

选区超过32768帧可试听，但不能载入音色，会提示SHORTEN CLIP。先缩短范围再Enter。整段长录音始终保留在SD。

### TRIM：精剪和真正保存裁剪

1. 左右选TRIM，Enter进入。
2. 上下选START或END，左右改边界；普通约10ms，Fn+左右精调1个源采样点。
3. 琴键可以试听当前选区。
4. 下移选中 **SAVE TRIM**，按Enter。
5. 看到 **TRIM SAVED - OUTSIDE REMOVED** 表示成功。

SAVE TRIM会生成一份只包含选区的新WAV，并载入它，新的START为0；保留音色参数。它不会把滤波和LFO烘焙进音频。

原始录音文件仍保留，避免破坏别的音色引用；“裁掉外面”是指新文件不含选区外音频。已绑定SLOT时会更新该槽；未绑定时仍需Ctrl+S保存到槽才能交给STUDIO使用。普通采样可Ctrl+Z恢复上一次音频编辑；基础源不做PCM撤销。

## TONE：导航和参数总表

进入TONE后先高亮**分组栏**：左右选效果组，Enter或下进入参数。参数中上下选格、左右改值。Enter／Backspace回分组栏，分组栏Backspace退出编辑；Tab也可退出编辑。琴键可在分组栏和参数中试听。

每组最多四格横排，上方保留波形。分组多于五个时，左右会自动滚动。普通采样有SOUND／ENV／FILTER／FX／LOOP／PITCH／LFO；基础源隐藏LOOP，增加OSC。

### SOUND：发声方式和音量

| 参数 | 意义 |
|---|---|
| ROOT | 素材原本的音高标记，用于计算演奏时的变调；基础源隐藏 |
| MODE | ONE SHOT／KEY GATE／KEY LOOP；基础源隐藏 |
| GAIN | 音色音量0～100%；0会静音 |
| AUTO | 自动电平，按选区提升小音量素材，最多32倍；也可能放大底噪 |

ONE SHOT按一下播一次，适合敲击；KEY GATE松键释放，但到素材结尾也结束；KEY LOOP按住循环，松开按RELEASE淡出。要持续弹奏录音音色，选KEY LOOP并让SUSTAIN大于0。

### ENV：音量包络

| 参数 | 意义／范围 | 怎么试听 |
|---|---|---|
| ATTACK | 起音时间0～1000ms | 设300ms，重新按键，音量慢慢升起 |
| DECAY | 从最大下降到持续电平的时间0～2000ms | SUSTAIN设30%，DECAY设500ms |
| SUSTAIN | 按住时的音量0～100% | KEY LOOP下长按比较 |
| RELEASE | 松键淡出时间5～2000ms | 设500ms后松键听尾音 |

ATTACK不能为负，0表示最快起音，仍有短防点击淡入。改变ATTACK／DECAY后要重新按键，已处于持续阶段的音不会重新起音。SUSTAIN=100%时DECAY无下降可听；SUSTAIN=0会在按住时也衰减到无声。短素材播完后，RELEASE不会凭空延长录音。

### FILTER：明暗与一次扫频

| 参数 | 意义 |
|---|---|
| CUTOFF | 低通截止频率，约30～10000Hz；OFF旁路，越低越暗 |
| RESO | 截止附近的共振，0～90% |
| SWEEP | 起始截止偏移-100～+100；正值先亮后暗，负值先暗后亮 |
| TIME | 回到CUTOFF的时间0～2000ms，0不产生扫频 |

SWEEP在每次新音开始运行一次。**调SWEEP不会再自动改CUTOFF**。CUTOFF在顶端时正向变化受限，请手动降低CUTOFF再试。纯正弦本来就缺少高频，低通变化可能不如SAW明显。

### PITCH：调音与一次滑音

| 参数 | 意义 |
|---|---|
| TUNE | 整个音色移调-24～+24半音 |
| FINE | 微调-100～+100音分；100音分为1半音 |
| SWEEP | 起始音高偏移-48～+48半音；正值从高落下，负值从低升上 |
| TIME | 回到正常音高的时间0～2000ms，0关闭滑动 |

PITCH和FILTER的SWEEP时间不跟随BPM。TIME普通左右10ms，Fn+左右1ms；滤波SWEEP普通5%、Fn精调1%。

### FX：失真和位深

| 参数 | 意义 |
|---|---|
| DRIVE | 软失真0～100%；增加粗糙度与谐波，0关闭 |
| BITS | 4～16bit幅度量化；16为原精度，越低越颗粒化 |

8bit对较响持续音可能只增加轻微噪声，4bit更明显。对比时先设DRIVE=0、CUTOFF=OFF，避免其他效果掩盖变化。

### LOOP：普通采样的持续区

| 参数 | 意义 |
|---|---|
| REGION | FULL循环整个选区；CUSTOM使用独立循环区 |
| LOOP IN | 持续循环起点，开头仍从TRIM START播放 |
| LOOP OUT | 到这里跳回IN，终点不包含在循环中 |
| XFADE | 接缝交叉淡化，减轻咔嗒声 |

改CUSTOM或IN／OUT会开启KEY LOOP。先录一声“啊”，把IN放在起音后、OUT放在稳定声音末端，按住琴键；开头只播一次，中间持续循环，松键按RELEASE淡出。

IN／OUT限制在TRIM选区内，普通左右约10ms，Fn+左右精调1点。XFADE普通约1ms、Fn精调1点；默认64点，上限取2400点与循环长度1/4的较小者。太短的循环会变成有音高的嗡声。基础源已经按键持续，不显示这一组。

## 双振荡器 OSC

仅基础音源路线显示：SOUND LAB → BASIC SOURCES创建 → TONE → OSC。

| 参数 | 意义 |
|---|---|
| A WAVE | 主波：SINE正弦／TRI三角／SQUARE方波／SAW锯齿／NOISE噪声 |
| B WAVE | 第二波：OFF或同样五种波形 |
| MIX B | B占比0～100%；0只有A、50各半、100只有B |
| B TUNE | B相对A音程-24～+24半音 |

B默认OFF。+7为五度、+12高八度、-12低八度。混合按比例分配，总增益不会简单翻倍。先试A=SINE、B=SAW、MIX B=35%、B TUNE=+12，再按住琴键调整。

两个相同频率、相位的正弦混合可能听不出区别；换不同波形或音程更明显。TUNE／FINE作用于整个音色，B TUNE只改第二振荡器。当前没有独立B音分失谐、第三振荡器或PWM。

## LFO：持续变化

基础源与普通采样都可以使用TONE → LFO。它持续重复，与SWEEP只运行一次不同。

| 参数 | 意义 |
|---|---|
| TARGET | OFF关闭；PITCH音高；FILTER明暗；AMP音量 |
| SHAPE | SINE平滑，TRI线性往返，SQUARE高低切换，SAW渐变后跳回 |
| RATE | 0.1～20.0Hz，即每秒几轮；普通左右0.5Hz、Fn精调0.1Hz |
| DEPTH | 深度0～100%；普通5%、Fn精调1% |

- PITCH深度100%约上下各2半音；10%约上下各20音分。
- FILTER在手动CUTOFF附近摆动，深度100%为上下各半个旋钮范围，超过上下限会受限。
- AMP深度100%在静音到原音量之间摆动，不额外抬高峰值。

每个音符按下时独立启动，长按持续运行，松键按RELEASE结束。目前RATE不与BPM同步。FILTER没变化时，先手动把CUTOFF调到中间并选SAW试听。

## 波形与黄色曲线

青色为处理后的音频预览，黄色为包络／调制示意；这是离线参考图，不是实时示波器。

| 标记 | 怎样看 |
|---|---|
| 1 CYCLE | 基础周期波的一轮形状 |
| OSC VIEW | B有不同音程时，以A周期长度截取的混合片段 |
| CLIP | 普通采样选区的一次波形 |
| ENV TIME | 音量起音、衰减、持续及松键释放示意 |
| PITCH TIME／FILTER TIME | 一次滑音／扫频方向和时间 |
| LFO TIME | 一轮LFO形状；速度看RATE |

**青色单周期与黄色时间曲线的横轴不是同一时间尺度。** 单周期预览为了稳定看形状，暂时忽略ADSR、SWEEP和LFO的长时间变化；调这些参数主要看黄色线、听真实声音。基础CUTOFF／RESO／DRIVE／BITS／GAIN和OSC混合会影响青色形状。

因此调ATTACK不会把基础正弦永久变成另一种波形；它改变的是每次发声的起音。普通录音的完整选区预览还会受音量包络影响。细小的8bit或滤波变化也可能在像素图上不明显。

## 音色保存及交给 STUDIO 使用

1. 调好后按 **Ctrl+S**，进入SAVE SOUND / SD。
2. 上下选SLOT 1～4；要改名按N，输入后Enter。
3. Enter保存。已有音色出现Replace this sound?时，**再按Enter确认覆盖**。
4. 看到 **SAVED TO SD SLOT …** 才算完成。
5. Ctrl+Tab回首页，进入STUDIO，选S1～S3进入详情。
6. 按A循环到对应SMP1～SMP4，按琴键演奏。

Ctrl+L可重新读取音色验证。标题的“*”表示当前有未保存修改，“^S SAVE”是Ctrl+S提示。回首页会保存LAST工作状态，但这不能代替保存SLOT供STUDIO调用。

四个SMP槽是全局音色库，覆盖某槽会影响使用它的其他项目。修改参数不改变原始WAV；PLAYER播放原WAV不会听到这些参数。

SD主要位置：

| 路径 | 内容 |
|---|---|
| /PocketSynth/Samples/ | 原始录音、基础源、裁剪及处理生成的WAV |
| /PocketSynth/Sounds/SLOT1.psmp ～ SLOT4.psmp | 音色设置，引用WAV并保存参数 |
| /PocketSynth/Sounds/WORK.psmp | 上次工作状态 |

备份时建议复制整个 **/PocketSynth/** 文件夹，仅复制psmp而缺WAV会无法发声。v0.25声音设置为PSMP06，兼容读取旧格式；新版保存的声音需要新版固件读取。

普通采样FILES中PROCESS AUDIO可做NORMALIZE、REVERSE、REMOVE DC、FADE EDGES及音频撤销，写入独立素材。EXPORT WAV导出素材，不是把所有TONE效果烘焙成音频；完整处理后重采样导出尚未实现。

## PLAYER：WAV／MP3 播放器

从SD根目录开始，可逐层进入文件夹，浏览整个卡。

| 操作 | 按键 |
|---|---|
| 文件列表选项 | 上／下 |
| 进入文件夹／播放文件 | Enter |
| 文件列表返回上级 | Backspace |
| 刷新当前目录 | R |
| 播放／暂停 | 播放页Enter或Space |
| 前／后跳5秒 | 播放页左／右 |
| 当前目录上一／下一首 | 播放页上／下 |
| 播放器音量 | -／=，每次5%，独立于项目音量 |
| 列表／播放页切换 | Tab |
| 停止并回列表 | 播放页Backspace |
| 回模块首页 | Ctrl+Tab |

目录每批48项，末项继续按下读下一批，首项按上回上一批；“+”表示后面还有内容。这里只列文件夹及可播放文件。路径最长127字节；中文名可能受屏幕字体限制，短英文路径更容易识别。

支持16bit PCM WAV（8～48kHz、单／双声道）和常见MP3 Layer III。24bit／浮点WAV不支持。立体声合成为单声道。MP3时长和跳转为估算，标“~”，VBR文件可能有偏差。播放器流式读取，无需把整首歌装进RAM。

## 快速配方与常见问题

### 四个音色配方

开始前从BASIC SOURCES选音源，按以下设置，再重新按键试听。

| 玩法 | 参数 |
|---|---|
| 激光／电子鼓 | SINE，PITCH SWEEP +24，TIME 150ms；每按一次音高快速下降 |
| 上升音 | PITCH SWEEP -12，TIME 500ms |
| 持续哇音 | SAW，CUTOFF约45、RESO 25%；LFO FILTER、TRI、2Hz、DEPTH 50% |
| 复古脉冲 | LFO AMP、SQUARE、4Hz、DEPTH 80%；可加BITS 6～8 |

### 按住只响一下或越来越暗

普通采样检查MODE是否KEY LOOP、SUSTAIN是否大于0。再检查FILTER SWEEP是否把音色逐渐变暗、CUTOFF是否过低，以及AMP LFO是否处于低点。ONE SHOT本来只播放一次。

### 参数改了听不出来

ATTACK／DECAY要重新按键；RELEASE要松键；DECAY在SUSTAIN=100%时没有下降。滤波对纯正弦可能不明显，用SAW更容易比较。B关闭时MIX B和B TUNE无效；LFO TARGET=OFF或DEPTH=0时不会变化。基础波形单周期图不会展示整段起音过程。

### 音量太小或无声

依次检查项目MASTER／播放器音量、轨道静音及音量、GAIN、SUSTAIN、CUTOFF。普通录音可开AUTO提高小信号，但也会放大底噪。SMP还需确认SD和它引用的WAV存在；四复音限制不会让一整条轨道永久无声。

### 保存后仍看到EMPTY

先确认所在的是STUDIO项目槽还是SOUND LAB音色槽；再确认LOCAL或SD来源。只改名字不等于保存，覆盖确认页也还没完成。执行SAVE并看到成功结果后，用LOAD读取同一来源、同一槽验证。

### 没有出现在声音列表

PLAYER浏览全卡；SOUND LAB的OPEN WAV只看/PocketSynth/Samples/，且不直接导入MP3。两处用途不同。

### 当前尚未提供的功能

自动七和弦、独立Sub／Detune、PWM、波形折叠、FM、环形调制、包络重复／往返、处理后WAV重采样导出、切片和颗粒尚未实现。四复音可以手动弹七和弦；B TUNE=-12可做低八度叠加。
