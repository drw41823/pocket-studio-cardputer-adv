# v0.25.1：无SD音色切换修复

无SD时切换到SMP曾依次尝试多个音色槽，并触发重复SD.begin挂载，造成界面长时间无响应。本版把编曲音色切换与SD挂载分离：已知无卡时跳过SMP并继续基础波形；SMP载入只能使用已挂载的卡，不会隐式重试挂载。加载工程遇到无卡且没有缓存的SMP时回退到基础波形，音符不删除。已在RAM中的采样可以继续发声。

插卡后请先从首页进入SOUND LAB或PLAYER显式挂载，再回STUDIO选SMP；也可以插卡后重新启动。已有LOCAL/SD项目与音色格式不变。

新增无卡连续切换8万次、零存储回调、SD四槽选择与缺失槽回退测试；共十套主机测试与ESP32构建通过。无硬件连接，尚未实机验证。安装器重装仍会覆盖NVS内部存档，请先备份；单独更新应用镜像需由熟悉地址/布局的用户操作。
